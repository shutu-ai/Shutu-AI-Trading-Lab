# M3.5 策略轨报告

| 字段 | 值 |
|---|---|
| 受测策略 | B2_single_rule（透明 MA 交叉，冻结参数 short=2, long=4） |
| 参数来源 | `m3-r2-batch-1` Train/Validation 预算化选择（`select_ma_params`），冻结于 M3-R2 官方批次；**非前向结果反推** |
| 策略哈希 | 由 `strategy_hash` 规范摘要绑定（arm + 规则定义 + 参数），每次 `PREDICTION_LOCKED` 入链 |
| 前向证据状态 | **`S=INCONCLUSIVE`，`evidence_state=NOT_EVALUATED`** |
| 部署状态 | `NOT_DEPLOYED`（无真实运行；SYNTHETIC_REPLAY 会话非部署） |
| 策略角色 | `NONE`（无 Champion/Challenger 流程，不建立） |
| 最终 Holdout | `SEALED_NOT_MATERIALIZED`（未触碰） |

## 1. 本阶段证明了什么（仅工程）

- 一条**冻结的透明规则**能在事件流上执行"先锁定、后等待、最后一次性评分"的完整前向管线；
- 决策与回测臂逐点等价（防漂移守护），因此被锁定的就是 M3 冻结的 B2 定义本身；
- 预测内容 = 敞口决策（LONG/FLAT）+ 参考收盘摘要，锁定后不可变（重投即 DUPLICATE/CONFLICT）；
- 评分规则 = 预注册的 hit/miss/no_claim/flat_close 计数（合成夹具上的管线一致性统计）。

## 2. 本阶段不证明什么（显式清单）

- **不证明任何 alpha**：hit/miss 是合成趋势+振荡夹具上的方向计数，数据形态由公式决定，无市场含义；
- **不证明 FORWARD_SUPPORTED**：0 个真实前向交易日；合成 5 日 ≠ 真实 5 交易日（任务书明令不得伪称）；
- **不证明策略有效性/经济价值**：无成本敏感性前向声明（成本模型仅在回测层），无净收益口径；
- **不改变 M3 结论**：M3 的 `E=PASS_WITH_SCOPE(SYNTHETIC_ENGINEERING_ONLY)` 与 `HIST_OOS_SUPPORTED`（若声明）均不因本阶段提升；
- **不触发任何晋级**：M3.5 短期 Shadow 一律只作工程证明（v2.1 铁律）。

## 3. 反向优化防护

- B2 参数继承自 M3-R2 的 Train/Validation 选择记录，本阶段零调参、零搜索；
- 预注册（含夹具哈希、评分规则、TTL）先于任何前向运行冻结并纳入代码身份；
- 每次 cohort 评分即对区间加污染标记（`ForwardCohort.score()` 单次语义，机械强制）；
- 同一夹具重放产生的重复评分被结构性拒绝（恰好一次不变量）。

## 4. 独立性披露

- 本阶段唯一 cohort：`m35-shadow-synthetic-replay-v1-s*`（SYNTHETIC_REPLAY 夹具）；
- 与历史滚动 OOS、合成/未物化 Final Holdout **无日期/资产/事件交叉**（不同数据域，夹具独立生成，哈希不同）；
- 该"独立"对**真实前向证据毫无贡献**：合成 cohort 永远不能与真实窗口合并计算或互相替代。

## 5. 结论

`S=INCONCLUSIVE`（维持）。策略证据不因 M3.5 工程通过而有任何提升；Live 资格无变化（无）。
真实前向窗口（≥5 个可观察美股交易日 + 故障恢复证据 + 0 未授权 Paper 单）必须由 S8 单独授权后采集，按预注册资格规则评估。
