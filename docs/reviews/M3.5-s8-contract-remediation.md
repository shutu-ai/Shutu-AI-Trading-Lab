唯一权威改为官方区间日线端点 `GET /v2/stocks/{symbol}/bars?timeframe=1Day&feed=iex&adjustment=raw&limit=10000&sort=asc` + **有界窗口**（start=会话 00:00 ET 含边界、end=真实接收时刻；页帽 5）。三层封死分钟线：请求契约 + 官方形状（`bar` 对象进 ranged 路径即 CONTRACT_SHAPE 拒绝）+ `NOT_A_DAILY_BAR` 盘中戳纵深防御（含盘后戳）。空 bars = 文档化"当日无数据"（MISSING_BAR 回执，0 事件 0 日数）；两根 bar = SCHEMA；分页按 `page_token` 链取尽、超帽 fail-closed；429/5xx 记为断连可采证据，400/401/403/404 是操作者侧错误（回执但**不算断连**）。事件确定性、digest、receipt↔journal 绑定、幂等、修订 CONFLICT 全部保留重验。旧夹具**原样钉为 `LEGACY_INVALID_VENDOR_CONTRACT`**（文件内标记 + 迁移记录），新 v3 形状夹具单列；legacy 分支冻结仅证据复现可用，真实采集在 runner 层结构性拒绝（exit 5，有测试）。

## 7. 残余风险（如实）

1. **`NOT_A_DAILY_BAR` 纵深防御依赖盘前戳约定**（官方未权威定义日线戳；示例佐证）。若供应商真实日线戳落在开盘后，采集将 fail-closed 拒绝并如实暴露——不冒充、不放宽；首个真实周期（操作者动作）即验证该假设。
2. 供应商收盘后不保证日线终稿：完成性 = 预注册轮询边际 + 修订走 CONFLICT 保守挂起（可能暂停评分等待人工复核）。
3. 静态检查不拦计算性动态导入/exec（既有声明边界）；receipt 链锚为单机模型。
4. 进程内 GET-only 守卫 ≠ 凭证原生只读：主机级出口隔离未证实前保持 `HOST_EGRESS_ISOLATION_UNVERIFIED`。
5. 新 SHA 的本地绿**不等于** REMOTE_VERIFIED；推送与首次真实采集均等待用户单独授权。
